# 🤖 AI Lab Bot

Telegram-бот для приёма заявок на разработку.

## 📁 Структура проекта

```
ailab_bot/
├── bot.py                  # Точка входа — запуск бота
├── config.py               # Настройки (токен, admin ID)
├── requirements.txt        # Зависимости
│
├── handlers/               # Обработчики команд
│   ├── start.py            # /start и главное меню
│   ├── services.py         # Услуги и цены
│   ├── order.py            # Оформление заявки (FSM)
│   ├── faq.py              # Частые вопросы
│   └── admin.py            # Панель администратора
│
├── keyboards/
│   └── keyboards.py        # Все кнопки и меню
│
└── data/
    └── services.py         # Данные об услугах, ценах, FAQ
```

## 🚀 Установка и запуск

### 1. Получи токен бота
- Напиши @BotFather в Telegram
- Отправь `/newbot`
- Скопируй токен

### 2. Узнай свой Telegram ID
- Напиши @userinfobot
- Скопируй цифровой ID

### 3. Заполни config.py
```python
BOT_TOKEN = "1234567890:AAF..."   # вставь токен
ADMIN_ID  = 123456789              # вставь свой ID
```

### 4. Установи зависимости
```bash
pip install -r requirements.txt
```

### 5. Запусти бота
```bash
python bot.py
```

## 🔧 Что умеет бот

- **Главное меню** — приветствие и навигация
- **Услуги** — описание каждой услуги с ценами и пояснением
- **Заявка** — 4 шага: услуга → описание → бюджет → срок
- **FAQ** — ответы на 5 частых вопросов
- **Уведомления** — заявка мгновенно приходит тебе

## 📝 Как изменить цены и услуги

Открой `data/services.py` — там все тексты, цены и FAQ.
Меняй прямо там, перезапусти бота.

## ☁️ Запуск на сервере (чтобы бот работал 24/7)

Рекомендую **Railway.app** — бесплатный хостинг для ботов:
1. Зарегистрируйся на railway.app
2. Создай новый проект → Deploy from GitHub
3. Добавь переменную окружения `BOT_TOKEN`
4. Готово — бот работает 24/7 бесплатно
